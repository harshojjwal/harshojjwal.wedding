# Harshita & Ujjwal — Wedding Invitation

## Run it
Open `index.html` in a browser.

## Publish it free
1. Create a GitHub account.
2. Create a new public repository.
3. Upload `index.html` and the `assets` folder.
4. In Settings → Pages, choose Deploy from branch → main → root.
5. GitHub will provide a shareable website link.

## Edit
All names, dates, venue, events, phone number and countdown are already filled in.
The Google Maps button searches for the supplied venue name.
Replace/add `assets/music.mp3` only with audio you are allowed to use.
